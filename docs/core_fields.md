# NileOps - Data Dictionary and Core Fields Documentation

## Project Overview
This document defines the core data fields required for each operational workflow supported in the NileOps MVP platform. Every individual data field is explicitly listed to ensure precise Document AI extraction, structured validation rules, and consistent processing across the system.

---

## 1. Customer KYC and Data Update (KYC)
* Full Name
* ID, Residence Permit, or Passport Number
* Date of Birth
* ID Expiry Date
* National Address
* Mobile Number
* Official Gateway Verification Status

---

## 2. Account Opening (Account Opening)
* Identity and Documentation Details
* In-Country Presence Declaration
* National Address
* Mobile Number
* Ultimate Beneficial Owner Declaration
* Active Current Account or Digital Verification Status
* Commercial Registration (CR) Number
* Commercial Registration Status with the Ministry of Commerce
* Foreign Investment License
* Corporate KYC Form and Source of Income Records

---

## 3. Bank Card Requests (Card Requests)
* Customer Name and Account-Linked ID Number
* Card Request Type (New Issuance, Replacement, or Renewal)
* Current Card Activation Status
* Monthly Account Statement
* Financial Eligibility and Repayment Record
* Credit Card Limit
* Transaction Type
* Police Report for Suspected Stolen Card Misuse
* Prior Card Closure Notice

---

## 4. Customer Complaints (Customer Service & Complaints)
* Customer Full Name
* ID or Residence Number
* Mobile Number
* Communication Channel
* Complaint Description and Details
* Complaint Reference Number or Transaction ID
* Disputed Transaction Amount

---

## 5. General, Shared, and Cybersecurity Policies (Common Framework)
* Customer Consent Acknowledgment
* Purpose of Personal Data Processing
* Access Logs and Security Audit Records
* Role-Based Access Control (RBAC) Matrix
* Device Identifier for Digital Transactions
